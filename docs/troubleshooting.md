# 常见问题

## Windows 中提示“仅支持 Windows”或“不支持此操作”

若通过 `link:` 安装并在 Harness 运行时更新源码，界面可能加载了新文件，后台仍运行此前导入的 Host 模块。旧后台没有端口或文件夹能力字段，也不认识新操作。

等待当前任务结束，完全退出 Harness，再重新启动。只刷新界面不能保证后台重新导入。0.10.2 的端口面板显示界面与后台版本，并在能力缺失时提示重新加载。未连接或没有当前项目会话时，点击打开文件夹也会说明原因。

## 文件夹没有打开

先打开一个明确的项目会话，再右键选择“打开当前工作区文件夹”。目录来自 Harness 工作区注册表，缺少关联时使用会话的 cwd。目录不存在、权限不足或非 Windows 系统会显示错误。浏览器预览只模拟打开，不调起真实资源管理器。

## 端口扫描未找到服务

仅扫描当前会话项目目录内能确认归属的 TCP 监听服务。相对入口、模块启动、权限不足或其他无法确认的进程可能不显示。插件不会按端口范围猜测项目归属；系统进程、Harness、Codex 和其他用户进程受到保护。

## 没有提示音

重新打开 Harness 后先点击宠物或试听一次来解锁音频，再检查勿扰模式、声音开关及音量。自定义音频仅保存在窗口 origin 对应的 IndexedDB；清除应用存储或更换 origin 后需要重新导入。

## 正式桌面验证范围

当前兼容目标为官方 Windows Harness 0.2.0-rc.2。逻辑测试、模拟交互及 Windows 工具调用已验证；正式桌面最小化后的音频与真实审批流程仍需实机验证。接口与历史验证记录见 [compatibility.md](compatibility.md)。
