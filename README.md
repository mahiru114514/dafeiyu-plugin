# 大肥鱼插件

DeepSeek Harness 窗口内宠物：任务提醒、运行计时和喝水休息提醒。

插件 **0.10.2**，面向 **Windows 官方 DeepSeek Harness 0.2.0-rc.2**。小伙伴只显示在 Harness 内容区，支持拖动、收起和位置记忆。设置面板的顶部栏与关闭按钮固定，滚动时始终可见。

- 主 Agent 正常结束或发生错误时发出短提示音；手动停止不播完成音。
- 审批、用户提问有独立提示音，点击气泡可跳到待处理会话。
- 只要任意 Agent 为 `running` 就计时，包括后台运行；多个 Agent 同时运行只累计一次。显示今日总时长，跨午夜分日记录。
- 喝水、休息默认每累计运行 **120 分钟**提醒，分别可设置 1–1440 分钟。可确认完成或延后 10 分钟运行时间。
- 提示音开关、音量、勿扰和减少动画均可设置。
- 右键宠物可检查并清理占用的项目端口，也可快捷切换勿扰、打开设置、收起/展开宠物。
- 右键 → **打开当前工作区文件夹**，直接在 Windows 文件资源管理器打开当前工作区；收起后的图标也支持。
- 完成音、确认音可分别导入本机音频，支持试听和恢复默认，重启窗口后恢复已导入文件。

## 十一种形态与动画

| 用户参考图 | 形态 | 切换条件 |
| --- | --- | --- |
| 抱枕参考图 | 抱枕睡觉 | Harness 在前台，连续 **10 分钟**无点击、键盘或滚动操作 |
| 招手参考图 | 欢迎回来 | 每次启动 Harness，前 **5 分钟**没有工作或提醒时 |
| 最新 P1：双手垂下、省略号 | 等你确认 | 存在未处理的审批或用户提问 |
| 最新 P2：双手脸旁、爱心 | 喝水/休息提醒 | 喝水或休息到期，尚未确认或延后 |
| 最新“最强”参考图 | 完成庆祝 | 主 Agent 本轮正常完成后展示 **20 秒** |
| 最新 P1：躺下、叉眼、“死掉了” | 运行失败 | error、max-tokens、blocked 结束后展示 **20 秒** |
| 最新 P2：举牌、疑惑 | 手动停止 | 用户主动停止后展示 **20 秒**，保持静音 |
| 饼干参考图 | 吃 tokens | 至少一个 Agent 正在运行 |
| 空碗参考图 | 等你投喂任务 | 启动 5 分钟后的一般空闲状态 |
| 大胶囊 P1 | 清理占用端口 | 端口清理面板打开期间 |
| 敬礼 P2 | 打开工作区文件夹 | 调起期间，成功后继续展示 **10 秒**；失败立即恢复 |

优先级为：等待确认 → 喝水/休息到期 → 工具形态（打开文件夹 → 清理端口） → 本轮结束形态（完成/失败/手动停止） → 工作 → 启动欢迎 → 无操作睡觉 → 普通空闲。两种提醒同时出现时先显示等待确认，确认处理后恢复健康提醒。仅确认喝水而休息仍到期时继续显示健康提醒；全部确认或延后后恢复当前形态。工作和提醒不会被睡觉状态覆盖；重新操作会唤醒。离开或返回窗口会重新计算无操作时间，其他应用的输入不参与判断。

关闭端口面板或切到设置后结束大胶囊形态；打开文件夹敬礼结束后，若端口面板仍在则恢复大胶囊，否则恢复当前工作或空闲。切换项目清除旧文件夹动作。收起宠物后调用这两个工具会展开，以便展示新形态。两种新形态也提供四帧动画，并支持后台暂停和减少动画；不会额外发声或改变计时。

完成庆祝仅由新通知触发，页面重载不重播历史完成；失败与手动停止分别显示各自新形态，不会显示完成庆祝。20 秒后恢复当前工作或空闲形态，结束气泡仍可手动关闭。只将官方用户取消原因识别为手动停止；内部卸载或父任务中止保持静默。宠物下方的小字已移除。

每种形态提供四帧循环动画：呼吸、招手、眨眼、吃饼干、晃碗；等待形态带省略号，喝水/休息形态带爱心，完成形态带“最强”字样、眨眼和轻微摆动；失败形态带漂浮小幽灵，手动停止形态有举牌、疑惑和眨眼。窗口失焦或隐藏时暂停动画；“减少动画”或系统减少动态效果设置会显示静态首帧。无操作判断只影响外观，Agent 在后台运行仍正常计时。

面板已隐去“宠物状态”设置区，十一状态仍自动切换。升级前已保存的睡觉间隔继续沿用，新用户默认 10 分钟。

## 导入提示音

点击伙伴打开面板，在“声音提醒”中分别选择“导入完成音”和“导入确认音”。导入后显示文件名，可试听或恢复内置提示音。支持当前客户端能够解码的 MP3、WAV、OGG、M4A、AAC、FLAC、WebM 文件，每个不超过 **5 MB、30 秒**，建议选择短音频。不支持或损坏的文件会显示原因，原有提示音保持不变。

手动停止仅做视觉提醒，不播放任何提示音。运行遇到错误时也使用自定义完成音；喝水/休息声音保持内置音。提醒的音量、勿扰及对应开关同时作用于自定义音频；主动试听用于检查声音，不受勿扰或提醒开关限制。

音频副本仅保存在当前 Harness 窗口的本地浏览器存储（IndexedDB），不上传，不写入每日统计文件。原文件移动或删除后，导入副本仍可播放；清除该应用的浏览器存储或更换窗口 origin 后需重新导入。预览与正式 Harness 的音频存储分开。每次重新打开窗口后，点击伙伴或试听以解锁声音。

## 右键清理占用端口

菜单第一项 **打开当前工作区文件夹** 读取当前会话所属的官方工作区目录，无关联注册项时使用会话的项目目录。直接调起文件资源管理器，方便查看文件或进行测试；不会自动运行项目命令。无当前项目会话、目录不存在或无法访问时，点击菜单会说明原因。路径只来自 Host 官方记录；浏览器不能提交任意目录。预览只模拟打开，正式插件才会打开本机文件夹。

右键宠物 → **清理占用端口…**，自动扫描当前 Harness 会话的项目目录。面板按进程汇总 TCP 监听端口，显示进程名、PID、程序路径和归属依据。选择 **释放端口** 后核对目标，点击 **确认释放**；取消或 Esc 不执行结束。一个进程监听多个端口时，结束这个进程会同时释放这些端口。操作后重新扫描项目服务；也可点击 **重新扫描** 刷新列表。切换会话立即清除旧列表和确认，并扫描新项目。

项目目录由 Host 从官方会话 `header.cwd` 读取，不使用输入端口、浏览器传入目录或任意 PID 推断归属。已知共享运行时 Node、Python、.NET、PowerShell、Java 必须有当前项目内的绝对入口脚本路径；原生程序可按项目内可执行路径识别。仅使用相对入口或模块启动（例如 `python -m …`）的服务可能无法识别，未确认归属的服务不会列入。只扫描 TCP 监听，不覆盖 UDP、文件锁或整个进程树。

此功能仅支持 Windows、当前用户权限和单个明确进程，不提权、不结束整个进程树。保护 Harness/宿主及其祖先进程、Codex、系统关键进程、其他用户及身份不可确认的进程。检查结果有效期 90 秒且结束令牌单次使用；过期或目标改变时需重新检查。结束会中断目标进程的任务，界面会在执行前确认。

右键菜单支持方向键、Home/End 和 Esc，也可切换勿扰、打开设置、收起宠物；收起后右键小图标可展开。

## 安装与升级

从 [GitHub Releases](https://github.com/mahiru114514/dafeiyu-plugin/releases) 下载安装包与 SHA256 文件。先在 Harness 侧栏进入 **插件 → 添加插件**，输入安装包的完整本机路径，例如：

```text
E:\大肥鱼插件\dsh-harness-pet-0.10.2.tgz
```

检查本地包信息后安装，再启用 `dsh-harness-pet` 组合包及其 `harness-pet` 行。若选择源码联调，也可输入 `link:E:\大肥鱼插件`；源码目录须已运行构建。

安装后点一下小伙伴，进入面板试听完成音和确认音。首次点击用于解锁音频；每次重新打开窗口后建议先试听一次。

CLI 替代路径：**等待任务结束，并完全退出 Harness** 后，在 PowerShell 执行安装随附的 CLI：

```powershell
& 'E:\deepseek_harness\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add 'E:\大肥鱼插件\dsh-harness-pet-0.10.2.tgz'
```

重新打开 Harness，在插件页面启用。关闭本插件可从插件页面停用组合包；统计文件会保留。

若已安装旧版，先停用并移除旧插件包，再添加 0.10.2 并重新启动 Harness。用户统计及原有设置保留。

若使用 `link:E:/大肥鱼插件` 安装，更新本地文件后仍需在插件列表停用并重新启用大肥鱼；若后台仍未更新，请完全退出再启动 Harness。刷新界面不会重新导入已运行的 Host 模块。端口面板现在显示界面/后台版本；后台未提供工具能力时显示重新加载提示，而不会误报 Windows 不支持。打开文件夹暂不可用时，点击菜单会说明原因。

## 使用与计时口径

点击角色打开设置；拖动改变位置，或聚焦角色后按 Alt + 方向键移动。面板中的“收起伙伴”变成小图标，点击可恢复。

等待确认时是否计时取决于官方 Agent 状态：仍为 `running` 就继续计时，进入 `idle` 就停止。计时衡量 Agent 活跃运行时间，并不衡量用户实际盯着屏幕的时间。电脑休眠或单次心跳间隔超过 15 秒的区间不补计；应用关闭期间不补计。

健康提醒默认仅显示气泡；打开健康提醒声音后，也只在 Harness 前台发声。运行完成、失败和等待确认声音按各自开关及勿扰设置处理。

设置及每日统计保存在 `%USERPROFILE%\.dsh\plugin-data\harness-pet\state.json`；自定义 `DSH_HOME` 时使用该目录下的同一路径。统计约每 30 次心跳保存，也在状态变化、操作和正常卸载时保存。异常退出可能丢失最后一段尚未保存的时间。损坏文件会保留，并在面板提示保存受阻。

## 本机验证

已完成逻辑测试、真实 Cordis 4.0.4 加载/卸载测试、官方浏览器模块格式检查，以及模拟事件页面的交互检查。**本次 0.10.2 尚未在官方桌面窗口完成实机验收**；尤其最小化后的声音播放与轮询延迟，仍需在实际 Harness 中验证。

首次安装建议这样验证：启动一个短任务并观察计时；任务结束检查提示；在需要确认时检查独立提示音；最小化后运行短任务，确认能听到声音。可暂时将提醒设为 1 分钟验证喝水/休息，之后改回 120 分钟。若插件加载异常，先从插件页面停用并查看诊断，勿使用版本豁免强行加载。

接口证据和测试范围见 [compatibility.md](docs/compatibility.md)。动画素材按用户提供的角色参考生成，不代表官方提供的美术资源。基础素材为 `assets/pet-animated-v2.png`，最新等待/健康提醒素材为 `assets/pet-reminders-v4.png`，完成素材为 `assets/pet-complete-v5.png`，失败/停止素材为 `assets/pet-endings-v6.png`；提示词记录在对应的 `assets/PROMPT-v2.md`、`assets/PROMPT-v4.md` 、`assets/PROMPT-v5.md` 与 `assets/PROMPT-v6.md`。

## 开发与预览

要求 Windows 和 Node.js 22.19 或以上版本。克隆仓库后安装依赖并构建：

```powershell
git clone https://github.com/mahiru114514/dafeiyu-plugin.git
cd dafeiyu-plugin
npm ci
npm run build
npm test
npm pack
```

生成的 `dsh-harness-pet-0.10.2.tgz` 可安装到 Harness。仓库不提交 `lib/`，构建脚本会从源码及动画素材生成它。

```powershell
npm install
npm run build
npm test
npm run preview
```

打开 `http://127.0.0.1:4318`。预览仅使用模拟 Agent，不调用模型，也不修改官方会话。使用按钮验证并发、完成、失败、停止、待确认和两小时提醒；模拟统计与实际统计分开。

预览另有启动欢迎、启动 5 分钟后、前台无操作 10 分钟、切到后台和返回前台控件。它们仅调整预览的模拟时钟与前台状态；正式插件使用 Host 进程启动时长及当前窗口的焦点/可见性判断。页面重载或插件热重载不会重新开始欢迎期。

构建产物在 `lib/`。React 使用 Harness 自带模块，CSS 和透明角色图嵌入客户端 bundle。运行时不访问外部网络。






工具形态素材为 `assets/pet-tools-v10.png`；内置 imagegen 生成的完整提示词和留白修订见 `assets/PROMPT-v10.md`。
